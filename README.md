# SK Rehan Ahamed - Personal Portfolio

Personal portfolio website showcasing embedded systems and automotive software engineering projects, experience, and technical skills.

## Overview

- Embedded Software & Automotive Systems
- AUTOSAR Classic, CAN/LIN/UDS, Microcontrollers, and HMI Systems
- Built with React, TypeScript, and Vite

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
